1. Download & Installation

Choose the installation method that matches your setup:

Method A: Standalone Windows Installer (Recommended)

Download uDrop-Setup.exe. It embeds the portable Node runtime and native tray binary inside one file, offers custom folder selection via Browse..., registers startup tray mode (OFF by default), and adds Explorer right-click sharing.

Method B: Portable ZIP (Zero Registry Changes)

Download uDrop-Portable-win64.zip, extract anywhere (including USB drives), and double-click udrop.exe to activate immediately—or run udrop.exe --tray to dock quietly in the taskbar.

Method C: Developer CLI (Node.js)

Terminal (npx / npm) 
npx @uxiom/udrop

# Or install globally:
npm install -g @uxiom/udrop

2. Windows System Feature Overview

Microsoft restricts the built-in Windows 11 Quick Settings menu (Win + A) exclusively to first-party system components. To deliver identical one-click ON/OFF access right beside your Wi-Fi and Bluetooth controls without UAC prompts or system file modification, uDrop runs as a native user-space notification area controller (udrop.exe).

Starts OFF by Default: On Windows startup, port 4040 remains closed and no background node.exe engine runs (~2 MB idle tray footprint) until you flip uDrop ON.

3. Shortcuts & Quick Triggers

Control / Shortcut Behavior
Ctrl + Shift + U Global hotkey from anywhere in Windows: toggles uDrop ON (opening the Glass QR Overlay) or OFF cleanly.
Tray Icon Left-Click Opens the compact Quick Toggle Flyout above your taskbar corner with the master ON/OFF switch.
Tray Icon Right-Click Opens context menu: Turn uDrop ON/OFF, Show Glass Pairing QR, Copy Connect URL, Open Downloads Folder, Open Web Dashboard, Quit uDrop Tray.
Explorer Right-Click → Share via uDrop Automatically switches uDrop ON, shares the selected file, and opens the Glass Pairing QR Overlay.
Desktop / Start Menu Shortcut Ensures the tray controller is running, flips uDrop ON, and shows the Glass QR Overlay.

4. Taskbar System Tray & Quick Toggle Flyout

The monochromatic [ U ] tray icon visually reflects uDrop state at a glance:

  • OFF State (Muted Gray Circle): Port 4040 closed; tooltip displays uDrop: OFF (Click to turn on).
  • ON State (White Circle + Green Status Dot): Transfer engine active on port 4040; tooltip shows active port.

Inside the Quick Toggle Flyout, you have instant access to:

  • Master Power Pill Switch: One click starts or stops the local transfer engine cleanly.
  • Live URL & IP Readout: Displays http://<host>.local:4040 and direct LAN IPv4 address.
  • Mesh Device Count: Shows connected slots on the UXIOM Ring.
  • Action Bar: Show Glass QR Overlay, Copy URL, Folder (Downloads\uDrop), Web UI, and Quit uDrop.

5. Kinetic Liquid Glass QR & Live Transfer Overlay

The moment uDrop switches ON, particles gather and assemble into a frosted acrylic-glass QR card on your screen with zero browser chrome or terminal windows.

  • Kinetic Assemble → Dismantle: Point your iPhone Camera or Android Camera app at the assembled QR code. Once paired, the QR pieces smoothly dismantle outward and morph directly into the Live Transfer Overlay Dashboard.
  • Live Transfer Monitor: Track active uploads/downloads in real time, open completed files immediately, drag-and-drop host files to share (or unshare with X), and click Pair Device (QR) anytime to re-assemble the QR.
  • Use IP / Use .local Switch: Toggle between mDNS hostname and direct IPv4 address if an Android device or router does not resolve .local hostnames.
  • Pin / Minimize / Turn OFF: Pin topmost with Pin, minimize to tray via Esc or X (keeping uDrop active), or click Turn OFF to close port 4040.

6. Windows File Explorer Right-Click Sharing

Enabled by default during Setup via per-user registry key (HKCU\Software\Classes\*\shell\uDropShare):

  1. Right-click any video, photo, PDF, or archive in Windows File Explorer.
  2. Select Share via uDrop.
  3. uDrop wakes the background engine (if OFF), registers the file over loopback HTTP, updates already-connected phones over Server-Sent Events, and displays the Liquid Glass QR Overlay labeled Sharing: <filename>.

7. udrop.exe Command-Line Reference

Command Description
udrop.exe --tray Starts single-instance Windows System Tray host in OFF default state.
udrop.exe --tray --on Starts tray host ON and opens the Glass QR Overlay.
udrop.exe --toggle Flips running tray instance between ON and OFF via Named Pipe IPC.
udrop.exe --qr Ensures uDrop is ON and pops open the Glass QR Overlay.
udrop.exe --share "<file>" Turns ON, registers the file outbound, and opens the Glass QR Overlay.
udrop.exe --silent Starts background HTTP/SSE transfer engine headlessly without tray UI.
udrop.exe --stop Calls graceful loopback POST /api/shutdown and terminates only uDrop's recorded PID.

8. Zero-App Phone Pairing & Transfers

  1. Ensure your PC and phone share the same Wi-Fi network (or use Hotspot mode).
  2. Turn uDrop ON via the tray or Ctrl + Shift + U.
  3. Scan the Glass QR Overlay with your phone camera to launch the embedded Progressive Web App in Safari or Chrome.
  4. Select photos, 4K videos, or files on your phone—transfers stream directly into C:\Users\<user>\Downloads\uDrop.

9. Bandwidth Smartness & Clean Cancellation

Single-File Dedicated Full-Bandwidth Pipe

Sending 1 file (such as a 40 MB video) uses 1 continuous XHR stream (concurrency: 1 for files up to 64 MB; 32 MB chunks up to 256 MB) with live 0%-100% progress and a 25s inactivity watchdog instead of a fixed wall-clock cutoff.

Multi-Video Queue & Cancel Purge

Batching multiple videos automatically switches to dual 4 MB/8 MB resumable pipelines with HTTP mobile stay-awake lock. Tapping Cancel aborts active XHR sockets, deletes partial files from disk, purges server session maps, and clears the phone queue immediately.

10. UXIOM 5-Node Ring Mesh

Connected devices dynamically claim slots around the host PC in a 5-slot ring topology:

  • [ U ] Host PC / Laptop: Anchors the mesh and performs zero-lag direct-offset writes.
  • [ X ] [ I ] [ O ] [ M ] Connected Devices: iPhone, Android, Mac, or guest laptops joining via QR scan.
  • Cross-OS Transit Bridge & Swarm Broadcast: iPhone [ X ] can send directly to Android [ I ] or tap [ ALL ] to broadcast to all active ring nodes over Server-Sent Events.

11. Router-Less Mode (Windows Hotspot)

When traveling without a Wi-Fi router or on client-isolated public Wi-Fi (on hardware drivers supporting Windows Hosted Network):

Terminal 
udrop --hotspot

Scan the terminal Wi-Fi QR code to connect directly antenna-to-antenna over 192.168.137.1.

12. Security, Privacy & Registry Footprint

  • Zero Elevation Required: Compiled with asInvoker manifest; no administrator UAC prompt needed.
  • User-Space Registry Keys Only:
    • Startup Tray: HKCU\Software\Microsoft\Windows\CurrentVersion\Run\uDrop
    • Explorer Menu: HKCU\Software\Classes\*\shell\uDropShare
    • Uninstaller Entry: HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\uDrop
  • Loopback Security Boundary: Host actions (/api/outbound/register, DELETE /api/outbound/:id, /api/open-folder, /api/open-file, /api/qr/popup, /api/shutdown) strictly reject remote sockets with HTTP 403.
  • PID-Safe Shutdown: Terminates only uDrop's own PID stored in %USERPROFILE%\.udrop\engine.pid.

13. Troubleshooting

  • Phone cannot reach .local address: Click Use IP on the Glass QR Overlay to encode your direct LAN IPv4 address (http://192.168.x.x:4040).
  • Connection blocked on Windows: Set your Wi-Fi network profile to Private and click Allow access if Windows Defender Firewall prompts on first transfer.
  • Public / Hotel Wi-Fi blocks peer traffic: Switch to direct hotspot mode using udrop --hotspot or connect via mobile hotspot.

14. Complete Uninstallation

Run uninstall.bat inside your install directory (default %LOCALAPPDATA%\uDrop\uninstall.bat) to:

  1. Cleanly execute udrop.exe --stop and exit tray processes.
  2. Delete HKCU\Software\Microsoft\Windows\CurrentVersion\Run\uDrop and HKCU\Software\Classes\*\shell\uDropShare.
  3. Remove Desktop/Start Menu shortcuts and application binaries (received files in Downloads\uDrop stay untouched).
